# 우리들의 연말 모임방 — 배포 가이드

이 폴더를 그대로 웹에 올리면 사이트가 돼요. 실시간으로 같이 모이려면 Firebase(무료)를 한 번 연결해야 해요.

## 폴더 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | 사이트 첫 페이지 (화면 크기에 맞춰 자동으로 확대/축소) |
| `app.js` | 모임방 전체 (캐릭터, 입장, 꾸미기, 댓글, 사진, 소리, 실시간 동기화) |
| `firebase-config.js` | Firebase 연결 정보 — **여기만 내 값으로 바꾸면 돼요** |
| `database.rules.json` | Firebase 보안 규칙 (자기 캐릭터만 수정 가능, 글자 수 제한 등) |
| `assets/` | 배경 이미지, 구름 |

`firebase-config.js`가 `YOUR_...` 그대로면 "나만 보이는 모드"로 동작해요. 연결 전에도 화면 확인은 할 수 있어요.

---

## 1단계. Firebase 프로젝트 만들기 (약 5분)

1. https://console.firebase.google.com 에 구글 계정으로 들어가서 **프로젝트 추가**를 눌러요. 이름은 자유롭게 정하고, Google 애널리틱스는 꺼도 돼요.
2. 왼쪽 메뉴 **빌드 → Authentication → 시작하기**를 누르고, **로그인 방법** 탭에서 **익명**을 사용 설정해요.
   - 친구들이 회원가입 없이 들어와도 각자 자기 캐릭터를 갖게 해 주는 설정이에요.
3. 왼쪽 메뉴 **빌드 → Realtime Database → 데이터베이스 만들기**를 눌러요.
   - 위치: **싱가포르 (asia-southeast1)** — 한국에서 가장 가까워요.
   - 보안 규칙: **잠금 모드로 시작**
4. Realtime Database의 **규칙** 탭을 열고, 들어 있는 내용을 지운 뒤 `database.rules.json` 내용을 통째로 붙여 넣고 **게시**해요.
5. 톱니바퀴 **프로젝트 설정 → 일반 → 내 앱**에서 웹 아이콘(`</>`)을 눌러 앱을 등록해요. Firebase Hosting 체크는 안 해도 돼요.
6. 화면에 나온 `firebaseConfig` 값을 `firebase-config.js`에 옮겨 적어요.
   - `apiKey`, `authDomain`, `projectId`, `appId`, 그리고 **`databaseURL`** 이 꼭 있어야 해요.
   - `databaseURL`이 안 보이면 Realtime Database 화면 맨 위에 적힌 주소(`https://...firebasedatabase.app`)를 그대로 쓰면 돼요.

> `apiKey`는 웹사이트에 공개돼도 괜찮은 값이에요. 실제 보호는 4번에서 넣은 보안 규칙이 해요.

---

## 2단계. 사이트 올리기 (Netlify, 약 3분)

1. https://app.netlify.com/drop 에 들어가요 (가입 필요).
2. 이 폴더를 통째로 끌어다 놓아요. 몇 초 뒤 `https://무언가.netlify.app` 주소가 생겨요.
3. 그 주소로 들어가서 입장 → 캐릭터 만들기 → 모임방까지 되는지 확인해요. 다른 기기(휴대폰)에서도 같이 열어서 서로 보이는지 확인해 보세요.

나중에 파일을 고치면, Netlify 사이트 화면의 **Deploys** 탭에 폴더를 다시 끌어다 놓으면 업데이트돼요.

---

## 3단계. 내 도메인 연결하기

1. 도메인이 없다면 가비아, 카페24, Cloudflare, Namecheap 같은 곳에서 구입해요.
2. Netlify 사이트 화면 → **Domain management → Add a domain** 에 도메인을 입력해요.
3. Netlify가 알려주는 대로 도메인 구입처의 DNS 설정을 바꿔요.
   - 가장 쉬운 방법: 구입처에서 **네임서버**를 Netlify가 알려준 4개로 바꾸기
   - 또는 `www` 같은 하위 주소만 쓸 거면 **CNAME** 레코드를 `무언가.netlify.app` 으로 추가
4. DNS가 반영되면(몇 분~최대 하루) HTTPS 인증서는 Netlify가 자동으로 붙여 줘요.
5. Firebase 콘솔 → **Authentication → 설정 → 승인된 도메인**에 내 도메인을 추가해 두면 좋아요.

모임방의 **초대하기** 버튼은 지금 열려 있는 주소를 자동으로 복사하니까, 도메인을 연결한 뒤에는 그 도메인이 복사돼요.

---

## 동작 방식

- 처음 들어온 사람은 익명 계정이 자동으로 생기고, 같은 브라우저로 다시 오면 닉네임, 한마디, 캐릭터가 그대로 불러와져요.
- 캐릭터를 만든 사람은 모두 모임방에 남아요. 지금 접속해 있지 않은 사람은 반투명하게 "자리 비움"으로 보여요.
- 걷기, 점프, 앉기, 바라보는 방향은 0.1초 간격으로 다른 사람 화면에 반영돼요.
- 말풍선 댓글은 모두에게 저장되고 실시간으로 보여요.

## 알아둘 점

- Firebase 무료 요금제에는 동시 접속 수와 저장 용량 한도가 있어요. 친구들끼리 쓰는 규모라면 충분해요.
- 다른 브라우저나 기기로 들어오면 새 사람으로 인식돼요(익명 계정이라서).
- 캐릭터나 댓글을 지우고 싶으면 Firebase 콘솔의 Realtime Database 화면에서 `players` 또는 `replies` 아래 항목을 직접 삭제하면 돼요.
- 이 폴더는 `index.html`을 더블클릭해서 열면 동작하지 않아요(브라우저 보안 때문). 꼭 Netlify 같은 웹 주소로 열거나, VS Code의 Live Server 같은 로컬 서버로 열어 주세요.
- 배경 음악은 저작권이 끝난 전통 캐럴(징글벨, 1857)을 8비트로 연주한 거예요. 배경 그림은 직접 생성하신 이미지라, 쓰신 생성 도구의 이용 약관에서 공개 사용이 허용되는지 한 번 확인해 주세요.
